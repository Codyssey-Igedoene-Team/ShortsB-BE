# 콘텐츠 준비 기준

## 제공 원칙

- 실제 도서 본문을 제공한다. 외국어 본문도 허용하며 한국어 번역은 필수가 아니다.
- 작품·판본·언어·출처·이용 권한 확인 근거를 기록하고, 확인된 콘텐츠만 서비스에 공개한다.
- 번역문·주석·삽화는 원작과 구분해 확인한다. 외부 API의 공개 여부 필드는 검토 자료로 사용한다.
- 원문과 AI가 생성한 추천 설명을 구분한다. 자동 번역은 현재 확정 범위에 포함하지 않는다.

## 확보와 저장

- 외부 공급원 후보는 `../openAPI.md`를 참고한다. 최종 공급원과 시연 작품 목록은 미정이다.
- 확보 → 본문 정리 → 순서 있는 구간으로 분할 → 출처·권한 확인 → 추천 데이터 검수 → 공개 순서로 준비한다.
- `books`에 도서·출처·권한 상태를, `book_segments`에 구간 순서·제목·본문을 저장한다.
- 권한 상태안은 `unverified`·`approved`·`rejected`이며, `approved` 콘텐츠만 읽기와 추천에 사용한다.
- 제공 중인 본문 변경은 저장된 읽기 위치에 영향을 주므로 변경 전 복원 기준을 정한다.

## 구현 전 확정

- 실제 사용할 작품·판본·언어와 콘텐츠 검수 담당자.
- 1장과 본문 구간의 대응, 문장·문단을 보존하는 분할 기준.
- 판본·언어·권한 확인 근거를 관리할 위치. 현재 스키마에는 각각을 위한 전용 필드가 없다.
