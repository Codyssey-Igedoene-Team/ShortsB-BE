## 파일과 필드

- `books.json`은 version·bookCount·books 구조다. 본문 필드는 text·pages·pageJoiner, 구조 필드는 pageCount·chapters, 무결성 필드는 textSHA256이다.
- 식별·분류: id·title·author·category·workType. 판본·언어: language·edition·editionLabel. 출처·안내: sourceURL·sourceName·licenseURL·licenseLabel·credits·translationNote·txtFile.
- pages는 0-based 순서 배열이며 chapters는 해당 배열의 `[start, end)` 범위다. 화면·업무 API 페이지 번호는 1-based로 변환한다.
- 입력 id는 외부 자료 식별자다. DB의 bigint ID와 동일하다고 가정하지 않고 가져오기 때 안정적으로 연결한다.
- TXT는 대용량 본문이므로 에이전트가 직접 열지 않는다. JSON 본문 값도 출력하지 않는다. 프로그램 처리는 본문을 대화·로그에 내보내지 않는 방식으로 수행한다.

## 페이지·검색 구간

- pages 항목 하나가 서비스 1페이지다. 화면 재배치나 종이책 판본 쪽수와 분리한다.
- 페이지를 검색 기본 단위로 사용하되 길면 문단·문장 경계를 보존한 내부 검색 구간으로 나눈다. 각 구간을 원본 페이지·오프셋에 연결하며 표시 페이지는 유지한다.
- 발췌는 검색 대목을 포함하는 연속 min(요청 쪽수, 전체 쪽수) 범위다. 끝부분에서 시작을 조정한다. 요청량이 크다는 이유로 짧은 작품을 제외하지 않는다.
- 첫 책·대비 책의 실제 발췌 수는 다를 수 있다. 전체 독서는 선택한 작품의 첫 페이지부터 시작한다.

## 구조 검증과 공개

1. 프로그램으로 bookCount·중복 ID·필수 메타데이터·빈 본문/페이지를 확인한다.
2. pageCount와 pages 개수, pages를 pageJoiner로 재결합한 값과 text의 일치, textSHA256을 확인한다.
3. chapters 범위·정렬·허용되는 포함 관계를 확인하고 잘못된 인덱스를 보고한다. 원본 순서·표기를 임의 변경하지 않는다.
4. CSV 작품 ID·제목과 도서 자료의 연결을 확인한다. 대비 1~3은 우선순위 없는 후보 목록이며, 실제 6개 축(결·시선·어조·태도·결말·시대·배경)을 유지한다. 본문 근거는 별도 검수 자료로 양쪽 원본 페이지/범위에 연결하고 설명과 함께 승인한다. 후보 자료 수신만으로 본문 검수가 끝났다고 취급하지 않는다.
5. 작품·판본별 이용 조건·출처·표시 의무를 확인한 자료만 승인한다. 구조 검증과 권한 검수는 별개다.

2026-11-01 로컬 준비 도구로 15개 작품·864페이지의 구조·페이지 재결합·SHA-256·챕터를 검증했다. 생성한 임베딩 입력의 원본 페이지·UTF-16 위치·해시·출처 메타데이터와 CSV 작품 연결도 확인했다. 본문은 출력하지 않았다. 일부 licenseURL·licenseLabel·credits의 null은 그대로 보존했다. 실제 모델 토큰/임베딩 검증·권한 승인·대비 근거 검수는 별도이며 구조·해시 일치만으로 원작 대비 누락이 없다고 주장하지 않는다.

## 저장 구조와 변경 관리

- 현재 schema.sql에는 books의 topics·moods·edition·language·source_url·rights_evidence가 이미 존재한다. 같은 메타데이터 필드가 없다고 설명하거나 중복 추가하지 않는다.
- book_segments는 원문 순서·본문을, book_relations는 양쪽 근거 구간을 연결할 수 있다. 페이지와 내부 검색 구간을 분리해 저장하는 상세 구조·외부 ID 연결·번역 안내 저장은 구현 전 설계한다.
- 현재 SQL은 초기 생성용이다. 이번 문서 수정에서 변경·적용하지 않으며 DB 등록·변경은 별도 작업이다.
- 공개 후 표시 페이지·본문이 바뀌면 기존 독서 위치·검색 구간·해시·벡터 재생성에 미치는 영향을 검토한다. 요청마다 본문 재분할을 수행하지 않는다.
- 외부 API는 사전 자료 확보·검토에 활용한다. 매 추천 요청에 전체 외부 도서를 수집하지 않는다. `openAPI.md`는 기존 후보 자료이며 수정 보류다.
