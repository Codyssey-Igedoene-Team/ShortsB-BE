# 서비스 정책

PRD를 기준으로 한 개발 초안. 별도 표시한 제안·미정 항목은 구현 전에 확정한다.

## 사용자와 인증

- 핵심 기능은 로그인 후 이용하며, 초기에는 구글 로그인만 제공한다.
- 인증 방식: 구글 소셜 로그인(OIDC) → 서버 세션 생성 → 세션 쿠키로 로그인 유지. 서비스용 JWT는 발급하지 않는다.
- 최초 구글 로그인 시 회원을 자동 생성한다. 사용자 식별은 `oauth_provider`와 `oauth_subject` 조합을 사용하며, 구글의 `sub`를 저장한다. 이메일은 식별키로 사용하지 않는다. [구글 공식 문서](https://developers.google.com/identity/openid-connect/openid-connect)
- 이메일은 필수 수집하며 구글의 확인 여부를 검증한다. 같은 소셜 계정으로 재로그인하면 검증된 이메일을 갱신하고, 기존 닉네임은 유지한다. 신규 닉네임은 구글 표시명에서 최대 50자로 정리한다.
- 동시 최초 로그인은 DB 유일 키와 PostgreSQL `ON CONFLICT`로 중복 생성을 방지한다. 다른 DB 오류를 중복 가입으로 숨기지 않는다.
- MVP 세션은 서버 메모리에 저장하고 비활성 만료 기본값은 30분이다. 서버 재시작·만료 시 재로그인한다. `user_sessions` 테이블·서비스 JWT·별도 비밀번호를 사용하지 않는다.
- 로그아웃 시 서버 세션을 무효화하고 세션 쿠키를 제거한다. 다른 사용자의 취향·독서 기록에는 접근할 수 없다.
- 상태 변경 요청은 세션 기반 CSRF 보호를 적용한다. 비로그인 허용 `GET /api/csrf`에서 토큰을 조회하고 로그인·로그아웃 후 다시 받는다. 로그아웃에는 인증과 유효한 토큰이 모두 필요하다.
- `local`·`prod` 프로필과 실제 DB·구글·프런트 환경변수는 각각의 실행 환경에서 설정한다. 로컬 쿠키의 `Secure` 기본값은 `false`, 운영은 `true`, `SameSite` 기본값은 `lax`다. 운영 도메인·브라우저 쿠키 동작은 배포 시 확인한다.

## 입력·기본 추천

- 입력은 발췌 쪽수 1~10 정수, 필수 카드 1개, 선택 자유 프롬프트다.
- 카드는 따뜻한 이야기·유쾌한 이야기·생각할 이야기·무엇이든 좋아요다. ANY 선택과 카드 입력 누락은 다르다.
- 과거 취향 배열 입력·별도 취향 등록은 현재 필수 흐름에 포함하지 않는다. 저장 여부와 요청 계약은 API 초안을 따른다.
- ANY 단독은 본문이 있는 승인 작품 중 작품별 균등 무작위로 먼저 책을 고른다. 구간 수를 기준으로 작품 선택 확률을 늘리지 않는다. ANY 단독의 기본 발췌는 첫 페이지부터 min(요청 쪽수,전체 쪽수)를 제공한다.
- 카드 3종은 사전 query 벡터, 자유 프롬프트는 요청 시 query 벡터를 사용한다. ANY 벡터는 만들지 않는다. 카드+프롬프트 유사도는 기본 40%/60%로 조합한다. APP_RECOMMENDATION_PROMPT_WEIGHT로 프롬프트 비중을 조정하고 카드 비중은 1-설정값이다.

## 발췌 페이지

- 기존 자료의 pages 항목 하나를 1페이지로 사용한다. 종이책·화면·검색용 내부 구간과 구분한다.
- 입력 배열은 0-based, 사용자·업무 API 페이지는 1-based다. 내부 변환은 가져오기 경계에서 명시한다.
- 본문 페이지를 임베딩 기본 단위로 삼고 길면 원본 페이지에 연결된 내부 구간으로 나눈다. 표시 페이지를 재분할하지 않는다.
- 실제 제공 수는 min(요청 쪽수, 작품 전체 쪽수)다. 짧은 작품을 요청량 부족으로 제외하지 않는다. 빈·잘못된·미승인 본문은 후보가 아니다.
- 검색된 대목을 포함하는 연속 범위를 제공하고 끝부분에서는 시작점을 조정한다. 요청량과 실제량을 응답·화면에서 구분한다.
- 대비 작품에도 원래 요청량을 적용한다. 예: 요청 10쪽이면 8쪽 작품은 8쪽, 20쪽 작품은 10쪽. 두 결과의 실제량 일치를 강제하지 않는다.

## 전체 독서와 진행

- 두 발췌 중 선택한 책으로 전체 독서를 시작할 때 서버가 첫 페이지·처음 위치로 세션을 생성한다.
- 회원·책마다 미완료 전체 독서 세션은 하나만 유지한다. 읽는 중인 책을 다시 선택하면 기존 세션·저장 위치를 반환한다. 완료한 책을 다시 선택하면 새 세션으로 첫 페이지부터 시작한다. 서로 다른 책은 각각 미완료 세션을 가질 수 있다. 동시 시작 요청도 중복 세션을 만들지 않도록 원자적으로 처리한다.
- 진행률·위치 저장은 전체 독서 세션에서 관리한다. 발췌 분량을 자동 합산하지 않으며 짧은 작품의 전문을 발췌로 봐도 전체 독서 완료로 만들지 않는다.
- 현재 위치와 최대 도달 위치를 분리한다. 재접속은 현재 위치를 사용하고 진행률은 최대 도달 위치와 전체 작품 분량을 기준으로 계산한다. 최신 상태에서 앞부분으로 돌아가면 현재 위치는 이동하되 최대 도달 위치·진행률은 감소하지 않는다. 최대 도달 위치를 모든 앞 페이지의 실제 열람을 증명하는 값으로 사용하지 않는다. 위치의 정확한 진행률 환산식은 구현 계약에서 정한다.
- 위치는 안정된 원본 페이지와 페이지 내 위치에 연결한다. UTF-16 오프셋 기준은 API 초안이며 다른 인덱스 단위와 혼용하지 않는다.
- 전체 마지막 페이지 끝 도달을 서버가 검증해 완료 처리한다. 반복 완료의 중복 기록과 완료 세션의 무단 재개를 방지한다.
- 진행 저장·중단·완료 요청은 조회한 저장 버전을 보낸다. 서버는 버전 일치 확인과 갱신을 원자적으로 수행하고 성공 시 버전을 증가시킨다. 불일치는 409와 최신 현재/최대 도달 위치·상태·버전을 반환하며 요청을 반영하지 않는다. 거절된 요청으로 최대 도달 위치도 바꾸지 않는다. 프런트는 변경 안내와 최신 기록을 반영하고 과거 요청의 버전만 바꿔 자동 재전송하지 않는다. 일시적 저장 실패의 재전송에도 같은 버전을 사용한다. 저장 주기·전송 묶음 세부는 후속 구현에서 정하며 전체 오프라인 서비스는 요구하지 않는다.

## 대비와 콘텐츠 승인

- CSV 축의 ‘결’은 전체 정서적 질감, 어조는 말투·표현, 결말은 마무리로 구분한다.
- 대비 축은 결·시선·어조·태도·결말·시대·배경 6개다. CSV 대비 1~3은 후보 목록이며 숫자를 추천 점수나 우선순위로 해석하지 않는다. 검토 중·승인·제외 상태를 구분하고 승인 관계만 사용한다. 첫 발췌 안의 실제 근거와 두 번째 발췌 안의 근거·설명 일치를 확인한다.
- 승인 관계·양쪽 작품 권한·근거 위치를 검증하며 근거 없는 대비를 생성하지 않는다. 기준 작품·대상 작품·축을 관계 식별 기준으로 삼으며 방향은 별도로 검수한다. 같은 작품 쌍도 축이 다르면 별도 관계다. 근거가 여러 페이지에 걸치면 필요한 범위 전체를 발췌에 담을 수 있어야 한다.
- 짧은 작품도 대상이지만 페이지 부족과 근거 부재를 구분한다. 근거 부재를 분량 축소로 해결했다고 취급하지 않는다.
- 판본·언어·출처·이용 근거를 기록한다. AI 한국어 번역 여부·교열 전 안내·중역 설명을 유지한다.

## 보류·추가 결정

- 기본 공유와 공유 카드 모두 무기한 보류다. P0/P1 구현·검증·완료 필수 조건에 넣지 않는다.
- 성과 측정 확장·최근 추천 제외·기록 기반 순위 개선은 기존 보류/P1 범위를 유지한다.
- KURE-v1의 GPU 기본 추론을 확인했고 벡터 저장은 PostgreSQL double precision[]·Spring 유사도 계산으로 확정했다. 도서·벡터 등록 SQL/코드를 작성했으나 DB 적용·실제 도서 벡터 생성·Spring 검증은 대기 중이다. 고정 revision·실제 GPU 연결은 추가 확인한다. 첫 추천/발췌 조회/도서 정보 코드를 작성했으나 실행 검증은 대기 중이다.
- 개인정보 보관·삭제, 운영 쿠키·프록시, 저장 주기·진행률의 세부 환산은 후속 확정한다. 세션 발췌는 최대 10개이며 초과 시 생성 순서가 가장 오래된 항목을 제거한다.

## 발췌 임시 보관과 대비 없음

- 발췌 ID·원래 요청 쪽수·카드/프롬프트·작품 ID·실제 페이지 범위는 현재 사용자 서버 세션에 임시 보관한다. 본문을 세션에 복사하지 않고 DB에서 다시 조회한다.
- 대비 요청은 발췌 식별자로 서버의 입력·범위를 확인한다. 클라이언트의 수정된 범위를 신뢰하지 않는다. 별도 발췌 DB 테이블은 만들지 않는다.
- 발췌는 세션당 최대 10개 보관한다. 초과 시 가장 먼저 생성한 항목을 제거하며 조회로 순서를 바꾸지 않는다. 저장된 본문 해시·전체 쪽수와 현재 자료가 다르면 409로 새 추천을 요구한다.
- 세션 만료·로그아웃·서버 재시작 등으로 임시 정보가 사라지면 새 추천을 요청한다. DB의 전체 독서 기록은 유지되며 재로그인 후 이어 읽는다.
- 첫 발췌에 적합한 대비 근거가 없거나 유효 대비 후보가 없으면 대비를 생략한다. 첫 작품의 전체 독서 시작은 계속 허용한다. 세션 소실·모델 장애·후보 없음은 구분한다.
